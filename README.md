# Kemi-link: демонстрация

Готовая сборка React и Django с публичным каталогом. Записи пользователей,
заявки и рабочая SQLite-база не включены. Админка и изменение каталога закрыты.

1. Создайте пустой репозиторий GitHub и загрузите содержимое этой папки.
2. Войдите на https://dashboard.render.com через GitHub.
3. Выберите New → Blueprint, подключите этот репозиторий.
4. Проверьте, что план Free, и запустите Deploy Blueprint.
5. Дождитесь Live и откройте выданный адрес *.onrender.com.

Бесплатный сервер засыпает после 15 минут простоя. Первый запрос запускает
его снова примерно за минуту. Каталог восстанавливается из demo-data.json.
Демонстрационные заявки сохраняются временно и теряются при перезапуске.
Письма не отправляются. Для настоящих заявок потребуется постоянная база.
Подробнее: https://render.com/docs/free

Это снимок сайта. После правок исходного проекта нужно заново собрать
frontend и экспортировать снимок для обновления репозитория.
